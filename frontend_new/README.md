# Повітря

Особистий дашборд температури та вологості. Vanilla HTML/CSS/JS, без збірки та залежностей. Бекенд і старий `/frontend` залишені без змін.

## Запуск

Потрібен Node.js 18+ (перевірено синтаксис на Node 24):

```sh
node frontend_new/server.mjs
```

Відкрити http://127.0.0.1:4173. Запустити свій Go-сервер окремо для реальних даних. Сервер фронтенду проксіює лише три GET-маршрути API на `http://127.0.0.1:3000`, тому зміни CORS у Go не потрібні. Він не запускає Go і не створює БД.

Перегляд прикладу: http://127.0.0.1:4173/?source=demo. Демонстрація вмикається лише вручну; помилка API ніколи не підміняє виміри прикладом.

За потреби:

```sh
PORT=4174 SENSOR_BACKEND=http://127.0.0.1:3000 node frontend_new/server.mjs
```

Можна розмістити статичні файли за тим самим origin, що й API, без Node-проксі. Просте відкриття `index.html` через `file://` не підходить для реального API.

## Логіка

- Поточний вимір має власний час. Успішна HTTP-відповідь не означає, що датчик онлайн.
- Вимір старший за 60 хвилин або більш ніж на 5 хвилин у майбутньому не дає підказки щодо опалення/провітрювання. Інтервал збору у поточному Go-коді — 30 хвилин.
- Кожен API-регіон незалежний: помилка тижневої вибірки не приховує поточні дані.
- API перевіряється раз на хвилину, коли вкладка видима, та після повернення до неї. Запити мають таймаут.
- Добовий графік показує останні 24 години, впорядковані за часом, а не за текстовим label. Проміжок понад 75 хвилин розриває лінію.
- Тиждень — сьогодні та шість попередніх календарних днів за Europe/Kyiv. Пропущені дні не замінюються нулями. Сьогодні — неповний день.
- Температура й вологість мають окремі автоматичні шкали. Значення доступні й у таблиці. Наведення на точку показує точний вимір.
- Мін./макс./середнє за добу обчислюються за доступними вимірами. Це вибіркове середнє, не зважене за часом. За тиждень — середнє доступних денних середніх, не середнє всіх сирих вимірів.
- Пороги не задані за замовчуванням: користувач обирає їх сам. Порожнє поле вимикає відповідну підказку. Зберігання — localStorage цього браузера. Це особисті орієнтири, а не оцінка якості повітря; датчик не вимірює CO₂.
- Джерело й період живуть у URL: `?source=demo&period=week`.
